## Resume project entry

**Healthcare Risk Adjustment Analytics App | Streamlit, Python, pandas, scikit-learn, statsmodels**

- Built an end-to-end synthetic payer analytics workflow across 5,000 members using utilization, chronic-condition, RAF, care-gap, member-month, and actuarial-value features.
- Trained Logistic Regression and Random Forest models to prioritize suspect members for documentation review, with the best model reaching 0.792 ROC AUC, 0.526 average precision, and 3.49x top-decile lift.
- Converted model probabilities into operational priority tiers, identifying a critical review segment with 74.7% suspect rate versus a 17.9% population baseline.
- Built a modern Streamlit dashboard with review-capacity simulation, provider strategy views, model explainability, scenario scoring, and downloadable risk adjustment worklists.

## Data analyst version

- Delivered analyst-ready outputs including a Streamlit dashboard, provider action tables, priority-tier summaries, top-member worklists, and visual reports for healthcare operations stakeholders.

## Data scientist version

- Operationalized predictions into a Streamlit decision-support app with scored member queues, provider-level intervention tables, and scenario scoring for healthcare risk adjustment action planning.
